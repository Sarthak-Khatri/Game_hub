# Image Assets

This folder contains image files for the Reaction Test game.

## Image Files:

- Background patterns or textures
- Game state illustrations
- Achievement badges
- Loading animations

## Image Format Recommendations:

- Use SVG for scalable graphics and icons
- Use PNG for images with transparency
- Use WebP for better compression (with PNG fallback)
- Optimize all images for web delivery

## Current Assets:

All visual elements are currently handled with CSS and SVG icons for optimal performance and scalability.
